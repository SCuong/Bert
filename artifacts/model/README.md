# Model Artifacts Directory

Thư mục này dùng để lưu trữ trọng số mô hình sau khi huấn luyện:
- `baseline_tfidf_lr.joblib`: Trọng số mô hình cơ sở TF-IDF + Logistic Regression.
- `bert_best_model/`: Checkpoint mô hình BERT fine-tune tốt nhất.

*Lưu ý: Các file trọng số mô hình có dung lượng lớn được loại trừ qua `.gitignore` và không commit vào Git repository.*
